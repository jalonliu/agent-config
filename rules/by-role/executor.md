# Executor Role - 执行器角色规则

## 定位

执行器负责具体任务实现，不做高价值判断。

## 上下文要求

- 只接收任务卡，不接收主脑完整规则
- 系统提示精简（约 7KB）
- 关闭 Skill 加载

## 任务卡格式

```markdown
## 任务
[具体描述]

## 约束
- [约束 1]
- [约束 2]

## 验收标准
- [标准 1]
- [标准 2]

## 已知背景
- [与任务相关的事实]
```

## 执行原则

1. 严格按任务卡执行，不自行扩展
2. 遇到歧义向主脑请示，不猜测
3. 完成后按验收标准自检
4. 记录执行过程和遇到的问题

## 模型选择

- Flash 级模型已跨过 Coding 基准线
- 选模型时考虑成本和速度，质量差异不大
- DeepSeek v4.1 Flash 等输出速度快（100-200 Token/s）
